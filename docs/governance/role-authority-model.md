# Role and Authority Model

The platform's first-class abstraction is not the Agent; it is the Role.

Each Role includes:

- Responsibility
- Authority
- Context Requirement
- Artifact Output
- Gate Boundary

## Role Pool Principle

Every Role should naturally support a Pool in the future, including:

- Production Planner Pool
- Executor Pool
- Guardian Pool

For the MVP, a Pool may contain only one instance. The architecture must not prevent future expansion.
