# Diagnostic export v1 evidence register

The files under `samples/` are **synthetic** examples generated by `generate_samples.py` from the test double in `tests/test_work_diagnostic_export.py`. They demonstrate the compact and full ZIPs, their individual Markdown/JSON entries and the `watt-work-diagnostic-v1` wrapper. They do **not** qualify real ECS Work, actual Steering, a real Guardian result or the production deployment. Both example ZIPs use the same synthetic Work ID; each is captured independently and has its own timestamp and hashes.

Run from the repository root:

```text
uv run --extra test python docs/evidence/admin-work-diagnostic-export-v1/generate_samples.py
```

The schema, authorization policy, capacity controls and capture boundary are in [the architecture contract](../../architecture/work-ai-diagnostic-export-v1.md). Test and live qualification results are recorded in `qualification.md`.

The optional browser smoke script `tests/browser_diagnostic_smoke.py` needs Playwright in a local test environment and an installed Microsoft Edge. It must point only to the isolated `tests/browser_diagnostic_app.py` fixture, never to ECS. The script checks a real ZIP download, an individual report download, lazy Work listing, and the server error notice.
