## D. Semantic classes and production intent

Canonical kinds include operational action, production goal, question, analysis,
exploration, design, correction, status, constraint and fact. Actions use a
versioned typed ontology; CREATE_BRANCH, SWITCH_BRANCH and
CREATE_AND_SWITCH_BRANCH are separate. Every argument retains provenance. Current
consent cannot be borrowed from an older request. A new branch name requires a
literal Human target; owner reality can bind an exact existing baseline.

Production intent carries objective, primary change, scope, exclusions, current
versus future status, bounded/systemic classification, new-Work disposition,
repository reference/requirement and Preview/review/delivery boundaries. Literal
target paths and write areas cannot be invented from prose scope summaries.
Missing core goal arguments block that goal independently of current acquisition;
optional implementation uncertainty does not block a concrete business goal.
