# Frozen protocol — semantic assumption review prototype

Authorized scope: one isolated ordinary34 Formation repair probe, using the
retained first Wire, complete 19-source inventory, existing Provider, local-edit
representation, Validator and independent Review contracts. No Work, G0,
Holdout, production change, automatic Consumer selection or runtime change.

Compared with the previous decision-revision probe, add the prior unadmitted
interpretation and its bound origin, an explicit assumption under review, a
challenge to its authority/entailment, preserved facts and reconsiderable fields.
The challenge is not a Fact or independent Review verdict. No replacement
Consumer, expected route edit or ready-made alternative mapping is supplied.

Before the single live call:

1. Bind original Wire, inventory, parent request/response/validation receipts,
   prior diagnostic feedback and prior interpretation response fingerprints.
2. Keep original feedback errors and constraints. Derive construction state with
   the unmodified existing Owner; never inject extra derived repair targets.
3. Confirm exact Owner reconstruction, unchanged instructions/output Schema,
   and refusal of provenance/decision identity drift without network access.
4. Save the exact request and fingerprints. Refuse another live call once the
   first has started, even after failure or unknown transport outcome.

Live profile: deepseek-flash, reasoning none, max_output_tokens 16384, timeout
120 seconds; one logical Formation call, no new retry or candidate allowance.
No independent model Review in this diagnostic-only trial. All deterministic
candidate checks available to this isolated probe still run unchanged.

Predeclared observations:

- **Semantic revision observed:** an actual change in proposed Consumer/disposition
  or an explicit alternative source-to-method interpretation in the public
  justification. Merely changing quote text or restating the same subject-to-scope
  inference is insufficient. A changed proposal is still untrusted.
- **Old assumption abandoned:** judge from explicit edits and the inspectable
  method justification, not inferred hidden reasoning. Removing/replacing a
  route alone does not prove every requirement is preserved.
- **Alternatives:** count only interpretations actually expressed in the response;
  do not synthesize a model alternative or demand extra unsupported routes.
- **Source/coverage preservation:** use original identity/coverage checks and the
  existing method-eligibility Validator where a decoded candidate is available.
  Observe changes to unrelated routes and all retained original failures.
- **Failure classification:** distinguish probe identity/construction failure,
  candidate contract failure, semantic choice error and absence of observable
  revision. Do not change gates or call again to obtain a favorable result.

The prior trial had invalid manually extended derived repair targets. This trial
corrects that wiring before inference. That is an additional experimental
difference, so the historical comparison is descriptive; one sample cannot
isolate causality or establish generalized convergence or C3 Closure.

Raw private inputs/responses stay on the isolated ECS; publish only fingerprints,
usage, edit/validation observations and analyst-attributed semantic summaries.
