This record describes inspected code, not Runtime Conformance Qualification or Human Acceptance. Final test/Work outcomes belong in report.md and exact receipts.

## Confirmed source of the C2 gap

C2 normal admission retained production goals, semantic Facts, exclusions, clauses and typed authority flags. The fulfillment consumer primarily used CONSTRAINT/requested_effects, which the real admitted IR did not contain. An empty binding set therefore did not describe the retained requirements. The static Protected Context consumer then treated governance/context requirements as implementation-source witnesses. Only a generic witness-not-observed failure survived; the specific rejected candidate was not durable. These are producer/consumer and evidence responsibility seams, not authorization to rewrite accepted Facts.

## Bounded repair and failure protection

Candidate formation has at most two candidates for one immutable basis, with one feedback repair. Each candidate has at most one independent semantic-plan validation call, with no validation retry; the explicit maximum is four model calls, subject to the existing tighter purpose/resource limits. All logical calls and usage are durable. The four-call bound counts model-runtime invocations; any existing controlled transport retries retain their separate retry_count and must be reported as actual HTTP attempts when available. This does not increase the existing transport retry policy. Existing Self-Refine records the repair/stop; there is no new coordinator, budget reset or effect execution. Verification candidates use the existing owner receipt carrier and same bounded discipline. A real artifact contradiction remains a Verification failure. Unsupported source/scope/phase, missing authority/evidence, incorrect revision and unresolved inventory cannot be promoted as completed.

Receipts retain bounded safe values, scrub credentials and reference exact original authority. Models cannot invent witnesses, tests, audit completeness, Human Decisions or independent Guardian results.

## Qualification limits to examine

CURRENT request intent does not necessarily mean that every lifecycle condition is due in static Verification. A mixed requirement needs its own current-content proof. A source-linked component plan preserves exact quotes/positions and original Fact references, is independently reviewed for semantic completeness and equivalence, and is deterministically checked against immutable sources, values, permissions, consumer contracts and actual lifecycle gates. Unique exact-source quote location can correct only a derived position; the raw candidate remains retained. Missing or ambiguous component evidence stays unresolved. This conservative boundary must be measured with actual normal admission and independent Holdout, not waived through a phrase alias. An observed context item with no Human record keeps that absence and its real provenance; no Human identity is fabricated.

The C1 controlled semantic oracle remains a controlled regression, not live user production. Development source overlays are explicitly classified and do not qualify the final image. All initial failures and skipped database tests are retained; exit zero with skipped cases is not a PASS receipt.
