## Proven common defects and bounded fixes

1. Method eligibility was confused with evidence satisfaction. An original
   `BOUND` Fact with an exact literal file operand could not even propose the
   existing Git Diff method, because the consumer expected `SCOPE`. The fresh
   negotiated adapter can propose this method without changing the Fact.
   Independent component Review and actual exact Git Diff evidence remain
   mandatory. Legacy requests retain their original negotiated contracts.
2. A current `ARTIFACT_CONTENT` contribution plus a future `CANDIDATE_SEAL`
   contribution was rejected as if all current fulfillment had been postponed.
   Current content now uses the existing exact Candidate source verifier;
   the future seal obligation remains at its existing Candidate Gate. A seal
   alone does not cover current content or authorize Human promotion.
3. Focused consumer regression proved that current open content `SCOPE` had
   the same static primitive mismatch even without a seal route. The same
   negotiated current-content consumer handles both lawful representations.
   It receives the complete original Fact reference, including original Scope,
   relation, value, qualifiers and Authority.
4. PostgreSQL end-to-end regression then proved that a passed original Fact
   with `Scope=None` could not supply evidence to its referring Clause: the
   linked consumer required the original Scope to equal a file path. It now
   uses the one exact, independently checkable target already observed in the
   producer's Candidate witnesses, with matching source, Candidate and Tree,
   within both contracts' allowed targets. Original Scope is retained. Guardian
   independently verifies this relationship; a Watt status declaration alone
   is insufficient.

These are B-class consumer capability defects. Ineligible identity, version,
Authority or evidence remains C-class refusal. No new Wire schema, FACT index,
Owner, coordinator, Alias, model retry, budget or permission has been added.
Model variance still uses the existing bounded Formation feedback.
