# WIC / SDD External Architecture Study — Source Evidence Ledger

Study date: 2026-09-15. Research only. External repositories were inspected read-only.

## Evidence classes

- **SOURCE_PROVEN** — implementation or executable test/configuration was inspected at the pinned revision.
- **DOCUMENTATION_PROVEN** — the pinned repository documents the behavior, but the implementing product/runtime source was not established.
- **OBSERVABLE_BEHAVIOR_ONLY** — a saved run, artifact, or evaluation output demonstrates behavior without proving the whole mechanism.
- **INFERENCE** — a bounded research conclusion derived from multiple observations; it is not a source fact.

Absence in a snapshot means “not established here,” not “the product can never do this.” A generated template proves what the workflow asks an agent to do; it does not by itself prove that the agent complies.

## Evidence-led conclusion

The strongest source-backed mechanisms are: delta-based change propagation, explicit cross-artifact consistency checks, requirement-to-test links, brownfield code inspection, compact context indexes, proportional-process exceptions, and replayable evaluation fixtures.
