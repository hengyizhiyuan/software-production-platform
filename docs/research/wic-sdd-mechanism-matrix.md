## Mechanism decisions

| Mechanism | Classification | Reason |
|---|---|---|
| Delta requirements with scenario-loss validation | **ABSORB** | Preserves change provenance and catches a deterministic class of semantic loss. |
| Read-only cross-artifact contradiction/coverage analysis | **ABSORB** | Improves decision quality without claiming authority or mutating truth. |
| Requirement/scenario/property/test identifiers | **ABSORB** | Creates traceable verification obligations when bound to exact revisions. |
| Brownfield inspection before specification promotion | **ABSORB** | Prevents stale documentation or remembered intent from overriding current Reality. |
| Replayable cases with source/model/policy/corpus provenance | **ABSORB** | Enables attribution and rejects invalid score comparisons. |
| Artifact dependency graphs | **ADAPT** | Useful internally; file existence and fixed ordering are not semantic readiness. |
| One-question-at-a-time interviews | **ADAPT** | Focus helps, but total question value and inference policy matter more than format alone. |
| Right-sized workflows / Work Patterns | **ADAPT** | Strong hypothesis; requires tentative recognition, rerouting, blended mechanisms, and measured ROI. |
| Repository standard indexes | **ADAPT** | Useful for context cost; need freshness, exact selection receipts, and authority boundaries. |
| Agent-driven spec drift repair | **ADAPT** | Discovery should create a proposed governed revision, not silently rewrite Human intent. |
| Universal user-visible SDD phases | **REJECT** | Constrains Human expression and creates workflow bureaucracy unrelated to every Motive. |
| Artifact/checkbox existence as readiness | **REJECT** | Proves structure, not semantic sufficiency or authority. |
| Project/repository/spec as Work identity | **REJECT** | Conflicts with Motive-bound Work invariants. |
| Self-review/generic tests as trust | **REJECT** | Conflicts with independent Verification and Runtime truth. |
| Final Pattern taxonomy and WIC Policy schema | **DEFER** | Evidence supports experimentation, not a frozen design. |
