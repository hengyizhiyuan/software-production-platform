# Watt — External Executor Pattern Matrix

Study baseline: 2026-09-10; completed 2026-09-11 (Asia/Shanghai). Research only. Read with the [architecture study](external-executor-architecture-study.md) and [exact revision/source register](external-executor-source-evidence.md).

**ADOPT** means retain a demonstrated mechanism/principle in the Blueprint requirements. **ADAPT** means preserve the mechanism but change scope, authority or failure semantics for Watt. **REJECT** means do not import the stated assumption/default; it does not reject the entire reference system. These dispositions authorize no code copying or implementation.

Evidence keys: **W** Watt, **C** Codex, **O** OpenHands Canvas, **S** SWE-agent, **A** Aider, **L** LibreChat, **B** LobeHub, **U** Open WebUI, **G** LangGraph, **T** AutoGen, **H** Claude Code. Exact source/test anchors are in the register. **NE** = not established in the inspected scope; **outside** = implementation lives outside this checkout. Neither means the complete external product lacks the capability.

## 3. Decisions by engineering problem

### Execution identity and durable continuity

| Pattern | Mechanism and why it exists | Source evidence | Limitations | Watt compatibility / decision | Blueprint implication |
|---|---|---|---|---|---|
| P01 — Runtime-owned agent loop | Codex/SWE/Aider host repeated model→action→observation cycles to support self-correction. | [C01](external-executor-source-evidence.md#c01), [S01](external-executor-source-evidence.md#s01), [A01](external-executor-source-evidence.md#a01) | Their task/session definitions do not govern Work intent. | **ADAPT:** autonomous HOW under versioned PWU. | Kernel owns local planning/tools; Steering only re-enters for material direction/boundary changes. |
| P02 — Reconstructible Session | Codex canonical rollout/history/settings preserve useful context across loaded/cold resume. | [C02–C03](external-executor-source-evidence.md#c02) | Conversation is not Work Truth; active process and fsync guarantees differ. | **ADAPT:** preserve session continuity as a projection over exact facts. | Session independent of Work identity; portable checkpoint references and schema versioning. |
| P03 — Attempt identity | SWE RetryAgent creates multiple runs; LangGraph counts node retries; Watt uses execution grants. | [S02](external-executor-source-evidence.md#s02), [G03](external-executor-source-evidence.md#g03), [W03/W06](external-executor-source-evidence.md#w03) | Same term covers different boundaries. | **REJECT** importing a foreign attempt definition; **ADAPT** explicit retry lineage. | Attempt is stable grant continuity; provider request retries/worker lease epochs are separate. |
| P04 — Pending successful work | LangGraph persists successful sibling writes when another node fails. | [G01](external-executor-source-evidence.md#g01) | Channel writes do not transact with shell/filesystem effects. | **ADAPT:** preserve completed step results plus effect receipts. | Resume incomplete work rather than rerun every task; journal external effects independently. |
| P05 — Generation fences | LibreChat rejects stale predecessor replacement and late generation publications. LobeHub uses owned locks and persisted cancellation. | [L01](external-executor-source-evidence.md#l01), [B01–B02](external-executor-source-evidence.md#b01) | Redis lease alone cannot stop an already running process or remote effect. | **ADAPT:** separate Attempt generation and worker ownership, propagate fencing. | Prevent late owners from publishing trusted/current results; quarantine overlapping unknown effects. |
| P06 — Explicit durability policy | LangGraph sync/async/exit modes trade persistence delay against crash windows. | [G02](external-executor-source-evidence.md#g02) | In-memory saver and exit-only saves cannot guarantee mid-run crash recovery. | **ADAPT:** effect-sensitive durable barriers; **REJECT** one cosmetic durability toggle as the recovery contract. | Durable pre-effect intent and post-effect receipts; cheap progress batching; define RPO/RTO by promised failure domain. |
| P07 — Client detach independence | Codex thread subscriptions and OpenHands backend routing distinguish client from execution host. | [C03](external-executor-source-evidence.md#c03), [O03](external-executor-source-evidence.md#o03) | Client death, worker death and machine loss have different surviving state. | **ADOPT** lifecycle separation; **ADAPT** actual hosting topology. | UI reconnects by stable ID/cursor without mission resend; supervised workers and persistent recovery state. |
| P08 — Chat/task persistence shortcut | Open WebUI registers asyncio tasks in Redis and saves partial responses; AutoGen exports agents. | [U01](external-executor-source-evidence.md#u01), [T02](external-executor-source-evidence.md#t02) | Task ID/agent JSON does not contain coroutine stack, queue or OS process. | **REJECT** equating stored chat/task identity with recoverable execution. | Reconcile active effects and restore explicit runtime state. |

## 4. Failure-case comparison and falsifiable outcomes

| Case | Mechanisms to adapt | Mechanisms to reject | Blueprint acceptance condition |
|---|---|---|---|
| A — model capacity | C05/B04 error taxonomy, W06 reconciliation, bounded fallback under same objective. | All errors→task failure; unlimited retry; separately recreate Work to recover provider capacity. | No-effect request retries within policy; possible effects reconcile; immutable failed Attempt retained; same PWU objective remains. |
| B — client restart | C03 server/client separation, L02/O03 event replay, G01/B01 state restoration. | Browser task identity as worker; assume saved chat restores active OS process. | UI close/reconnect never duplicates mission; worker crash test demonstrates checkpoint reconstruction and owned execution. |
| C — remote compact failure | C04 retained input/replacement, B03 rollback, portable original facts. | Drop old context before durable replacement; assume opaque summary portable; blindly keep sampling beyond context limit. | Compaction recoverable independently, criteria/source/unknown effects remain exact, no full implementation replay. |
| D — quota after partial work | S02 patch salvage, W06 independent Reality, G01 completed-result retention. | Clean reset by default; Attempt status used as a proxy for missing implementation. | Completed edits retained with provenance; only missing/stale verification and unfinished engineering repeated. |

## 6. Research limits and disposition discipline

- OpenHands Agent Server, SWE-ReX deployment internals and parts of LibreChat's imported agent graph were not available as source in these ten checkouts. Findings stop at inspected call boundaries. No substitute was downloaded.
- Claude Code's core session/compaction/worktree behavior remains claim-level where only changelog entries exist. The public hook/plugin code is not a surrogate for its private core.
- Open WebUI's selected backend lifecycle has source evidence but no targeted runtime-restart/tool-effect test was located. AutoGen pause tests demonstrate a custom cooperative agent, not universal pause.
- No runtime benchmark, provider request, repository mutation experiment or full reference test suite was performed. Watt latency figures are attributed historical observations. Source/test inspection supports semantics, not a measured reliability or performance SLA.
- Mechanisms with missing exactness are adapted with explicit Watt obligations; they are never promoted into “solved exactly-once”, “cross-repo atomic”, “provider-portable cognition” or “independent assurance” claims.

**Readiness contribution:** this comparison is sufficient for designing the Blueprint boundaries and fault tests. It is not a framework adoption decision, implementation plan, or production qualification.
