# Raw-language authority retirement

This audit concerns the canonical production path, not the existence of historical
fixture utilities. Human text remains provenance and model input. Syntax checks
validate spans, literal arguments, JSON structure and Git names; they do not
select positive operational intent.

| Previous path | Canonical disposition |
|---|---|
| `RepositoryAssetService._bound_interaction_actions` → raw `repository_actions` fallback | Removed. Consume current executable IR items and typed arguments. |
| DeepSeek fixed-phrase action binding after model semantics | Replaced with IRK typed validation. Structured operation-label aliases only. |
| `ExternalResearchService.requests_for_turn` → `explicit_search_intents`, technical/current keyword routers, second information-gap interpretation | Removed from production dispatch. Consume IR SEARCH_GITHUB/SEARCH_WEB/FETCH_PUBLIC_RESOURCE. |
| Raw `production_intent_evidence` in ProductionAdmissionTrigger | Removed. Current production is the structured IR goal. |
| Raw repository-acquisition recovery intent in admission | Removed. Current typed ACQUIRE operation is required. |
| Raw branch/current-Work status shortcuts before semantic compilation | Removed. Compile first; consume typed query/status and owner reality. |
| Raw non-mutating side-question guard overriding candidate | Removed from canonical assessment normalization. |
| Raw motive/primary-outcome rewrite and quoted-command guard | Removed from canonical assessment. Clause and speech-act/provenance contracts govern. |
| Progressive WIC privacy/reversibility/correction/constraint/production regexes | Retired. Dead regexes and helper bodies removed; consume IR and typed question boundaries. |
| Interaction strategy altitude, broad-goal and uncertainty regexes | Removed. Use compiler-provided altitude, uncertainty and IR kinds. |
| Guided design mode inferred from raw request | Canonical path uses structured production/design semantics. Historical DTO fallback is advisory. |
| Independent Fast Reception interpretation in controlled turn processor | Removed. Historical reception utilities/tests remain non-canonical. |
| Response realizer raw latest Human input | Removed from canonical envelope. Consume governed IR, Response Contract and actual owner results. |
| Existing lifecycle policy / connector authority | Preserve validators of typed operation, actor, resource, credential, exact Candidate and lifecycle state. They do not select operations by Human words. |
| Repository proposal discovery/forbidden-area keyword scoring | Governed IR path uses explicit typed fields and source evidence. Historical no-IR proposal fixtures retain their separate legacy fallback. |

`DeterministicWorkInteractionCapability` and legacy helpers in
`domain/response_contract.py`, `application/external_research.py`,
`application/wic_reception.py` remain explicitly non-production fixture/advisory
utilities. Their unit tests are not live language-generalization qualification.
No live DeepSeek path may fall back to them when typed IR is missing.
`_repository_branch_status_answer` formats actual governed repository/Work
reality; its legacy `content` argument is not a query classifier.

The regression harness uses declared typed oracles. Migrating those fixtures
cannot introduce phrase-specific behavior into product runtime. Static source
call inventory and live candidate/ledger receipts jointly support this audit.
